# A股量化交易系统（毛选版）

## 项目定位
个人散户量化交易系统，针对 A 股市场特性设计。
**不做高频 / 纯数学量化**，核心是「A股交易守则」+ 多因子选股 + 市场状态自适应仓位。
全免费数据源（Baostock 为主、AKShare 为辅），计划上 GitHub。

## 核心思想（毛选落地）
- **实事求是**：因子横截面 z-score 标准化，消除量纲；具体问题具体分析，策略随市场变化迭代
- **调查研究**：每交易日先判市场状态（牛 / 震 / 熊），再定仓位与因子权重
- **集中优势兵力**：分位数筛选，前 20% 买、后 20% 卖，不撒胡椒面
- **抓主要矛盾**：不同市场状态用不同因子权重表

## 市场状态判断（4 维度 + 慢牛专项，政策偏置已关闭）
- **BULL（牛市）**：满仓干，5 只，单只 25%；动量/反转/量价背离权重高
- **SHOCK（震荡/慢牛）**：轻仓试探，3 只，单只 20%；反转因子为主
- **BEAR（熊市）**：**空仓观望**（或极低仓位 1 只 15%）；保存实力，时刻留意市场
- **慢牛结构专项**：120 日高点回撤 <15% 且 60 日低点抬升 ≥3% 且均线未死叉且近 20 日跌幅不深 → 给牛市加分
（段3 亏 46% 教训：只看位置不看趋势，把见顶下跌误判成慢牛回调；已加趋势确认关）
- **政策偏置**：已关闭（bias=0），政策数据不可控，不让人工判断翻盘技术面

## 因子体系（19 个，横截面 z-score 后加权）
- 量价(7)：动量 / 反转 / 波动率 / 换手 / 均线排列 / Amihud 非流动性 / 量价背离
- 情绪(3)：涨停计数 / 换手异动 / 跳空
- 基本面(5)：PE / PB / ROE / 营收增长 / 市值 / 景气度 / 行业轮动
- 外围(4)：美股 / 港股 / 全球风险偏好 / 北向资金（沙箱外网受限，本地运行时启用）

## 组合级风控（2026-08-04 新增）
- **BEAR / 指数破位清仓**：指数 MA20<MA60 且近 20 日跌 >4% 时，清空持仓、停止开仓
- **组合回撤熔断**：总资金回撤达 -8% 时强制清仓，空仓冷却 10 个交易日
- **连续亏损冷却**：连续 3 次亏损降仓至 15%，连续 5 次暂停交易
- **单票止损/止盈/移动止盈**：-7% 止损 / +15% 止盈 / 盈利 +10% 后回撤 -5% 移动止盈

```
├── A股交易守则.md             # 四环境交易守则
├── data/                    # 数据存储
│   ├── stock_pool.csv        # 股票池（4400+ 只）
│   ├── daily/                # 日线数据（Baostock 缓存）
│   ├── backtest_equity.csv   # 回测净值曲线
│   ├── backtest_trades.csv   # 回测成交
│   └── results/              # 可视化报告 HTML
├── src/
│   ├── data_loader.py        # 数据下载与管理（Baostock 为主）
│   ├── stock_pool.py         # 股票池过滤（排除ST/退市/北交所/创业板/科创板）
│   ├── direct_data.py        # 裸 requests 备用数据源
│   ├── visualize.py          # plotly 交互式 HTML 仪表盘
│   ├── factors/              # 因子库（base/price_volume/sentiment/fundamental/money_flow/overseas）
│   ├── backtest/             # 回测引擎（engine.py / factor_analysis.py）
│   ├── strategy/             # 多因子策略（multi_factor.py）
│   └── utils/                # market_regime / position_manager / mao_principles
├── notebooks/                # 探索性分析
└── tests/                    # 测试
```

## 使用方法
```bash
python main.py pool        # 构建股票池
python main.py data        # 下载日线数据（Baostock）
python main.py regime      # 查看当前市场状态与仓位建议
python main.py backtest    # 运行回测（输出 equity/trades + 日志）
python main.py report      # 生成可视化报告 HTML（data/results/report_YYYYMMDD_HHMM.html）
python main.py factors     # 因子 IC/IR 分析
python main.py principles  # 毛选原则映射
python main.py overseas    # 外围市场快照
```

> ⚠ 样本内 + 短窗口滚动验证，不代表未来收益。

## 关键修复记录
- 因子权重 key 错配（`amount_ratio_20` → `vol_price_div_20`）：权重取不到导致选股近随机
- 回测核心循环无量纲标准化（PE/市值 vs 动量/波动率 量纲混战）→ 补横截面 z-score
- 信号粗糙（score>0 全买）→ 改分位数集中筛选（前/后 20%）
- **净值曲线起点 bug**：`engine.run` 只遍历有信号日，丢前期空仓段 → equity 起点变首日买入市值；改为遍历完整交易日，且 report 以配置初始资金(100000)为收益率锚

## 风险与局限
- 段2（6/22-7/13）仍亏 6.5%，BEAR/破位空仓虽保住本金但未能盈利，因子在震荡转弱市仍存负期望
- 样本内过拟合风险；walk-forward 窗口仍短，需继续滚动验证
- 外围市场因子在沙箱内无法取数（代理限制），本地运行时启用
- 滑点 / 涨停跌停为简化模型
- 创业板 / 科创板已排除（主板为主）
